# Checklist de produccion

- [ ] Ruleset revisado y firmado por el servicio juridico.
- [ ] Casos sectoriales de sanidad revisados por DPD, Seguridad y responsables clinicos.
- [ ] Tablas juridicas de Dataverse con escritura restringida.
- [ ] Auditoria y retencion de Dataverse configuradas.
- [ ] API protegida con Entra ID y grupos autorizados.
- [ ] Secretos del Custom Connector almacenados y con fecha de rotacion.
- [ ] Logs sin descripciones de proyecto ni respuestas sensibles.
- [ ] Pruebas de regresion juridica aprobadas.
- [ ] FRIA y DPIA integradas en el proceso cuando proceda.
- [ ] Version del ruleset visible en pantalla e informe.
- [ ] Flujo de revision humana antes de marcar una evaluacion como validada.
- [ ] Procedimiento de cambio legislativo y retirada de rulesets antiguos.
